## 作業W06 學習單（1 題）

**題目**：二項分配：n = 10，p = 0.2 ＋ 學號末兩碼 ÷ 100（末兩碼 45 → p = 0.65），求 P(X = 3)。

**資料**：學號末兩碼（每人不同）。

**繳交物**：Excel `=BINOM.DIST(3, 10, p, FALSE)` 公式列截圖，或手算公式與結果拍照。

**評分要點（Pass／Fail）**：p 與學號末兩碼一致；結果正確到小數第 4 位。
