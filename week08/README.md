## 作業W08 學習單（1 題）

**題目**：中央極限定理：靠泊時間 μ = 18、σ = 6 小時，隨機抽 n = 學號末兩碼 ＋ 20 艘。用 Excel 算標準誤 `=6/SQRT(n)`，再用 `=1-NORM.DIST(20, 18, 標準誤, TRUE)` 求樣本平均超過 20 小時的機率。

**資料**：學號末兩碼（每人不同）。

**繳交物**：Excel 截圖 1 張：n、標準誤、機率都在畫面上，**旁邊儲存格打上自己的學號與姓名**。

**評分要點（Pass／Fail）**：n 與學號末兩碼一致；標準誤與機率都算出來；有學號姓名。
