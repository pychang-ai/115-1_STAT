## 作業W03 學習單（1 題）

**題目**：用「我的 50 筆」的靠泊時間欄，建立 **7 組**分組次數分配表（組限、次數）。

**資料**：上課當天發下「我的 50 筆」個人資料表（版本印在你的學號卡上）：50 艘進港船舶的船型、噸位、靠泊時間。**本學期多週作業都用這份，請輸入 Excel 並保存。**

**繳交物**：Excel 截圖 1 張：次數欄公式列顯示 `COUNTIFS` 或 `FREQUENCY`。資料表是四欄，**靠泊時間在 D 欄**；若算出來的最小最大值是幾十到一百多，那是抓到噸位（C 欄）了。

**評分要點（Pass／Fail）**：次數合計 50；組距一致；用的是自己版本的資料。
