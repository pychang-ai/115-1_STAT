### 二、新聞來源
使用**上課當天**老師發下的 3 則海事新聞短文（A／B／C 版，依座號分配），不可自行更換。

### 三、題目
1. 從你拿到的新聞中找出 **5 個變數**，逐一填表：

| 變數名稱 | 質性／量化 | 離散／連續（量化才填） | 測量尺度（名目／順序／區間／比率） | 判斷理由（一句話） |
|---|---|---|---|---|
| | | | | |

2. 這則新聞的數據是怎麼蒐集的？屬於哪一種抽樣（簡單隨機／系統／分層／群集／便利），你怎麼判斷？
3. **自己設計**一個關於「本班同學」的調查問題，寫出母體、樣本與抽樣方式。

### 四、評分要點（Pass／Fail）
- 5 個變數來自指定新聞；每個變數都有判斷理由；第 3 題的問題是自己設計的。
