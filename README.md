### 母體與樣本

**Population（母體）** — 你真正想知道答案的那一整群對象，全部都算進來。  
　　*例*：想知道「高雄港所有進港船舶的平均靠泊時間」，這裡的母體就是該期間進港的全部船舶，例如當月 800 艘，不是你手上那 50 艘。  
　　*易混*：母體 ≠ 很多筆資料。母體是由「你的研究問題」界定的，不是由資料量大小決定的。

**Sample（樣本）** — 從那一整群對象裡實際被你抓來測量的那一小部分。  
　　*例*：從當月 800 筆進港紀錄中抽出 50 艘，記下船型、噸位、靠泊時間，這 50 筆就是你整學期要用的樣本。  
　　*易混*：樣本 ≠ 樣本數。樣本是那 50 艘船本身，樣本數 n = 50 是「有幾艘」這個數字。

**Parameter（參數）** — 描述整個母體的那個數字，通常你永遠不知道它真正是多少。  
　　*例*：800 艘船的真實平均靠泊時間 μ 就是參數。除非把 800 艘全部量完，否則你拿不到這個數。  
　　*易混*：參數 ≠ 統計量。參數用希臘字母 μ、σ、p，是固定但未知的；統計量用英文字母，是算得出來但會隨樣本變動的。

**Statistic（統計量）** — 只用你手上那份樣本算出來的數字。  
　　*例*：50 艘船的靠泊時間總和 920 小時，除以 50 得到 x̄ = 18.4 小時，這個 18.4 就是統計量。換一批 50 艘再算一次，數字會變。  
　　*易混*：統計量 ≠ 參數。18.4 是你這次抽到的結果，μ 是港口真正的平均；整門統計就是在處理這兩者的差距。

**Descriptive Statistics（敘述統計）** — 只把手上這份資料整理、算出來、畫出來，不往外講。  
　　*例*：算出 50 艘船的平均靠泊 18.4 小時、標準差 6.2 小時，畫次數分配表與盒鬚圖，這些都停在「這 50 艘」。  
　　*易混*：敘述統計 ≠ 推論統計。敘述統計的結論只適用你量過的那 50 艘，不能說「所以全港口就是 18.4 小時」。

**Inferential Statistics（推論統計）** — 用手上的小份資料，去推測那一整群你沒量到的對象。  
　　*例*：用 50 艘算出的 18.4 小時，推估全港 800 艘的平均落在 16.6 到 20.2 小時之間，這一步就是推論。  
　　*易混*：推論統計 ≠ 猜測。它會同時給你「推估值」和「可能錯多少」，光給一個數字而不講不確定性，就不算推論統計。

### 變數、抽樣與資料整理

**Quantitative Variable（量化變數）** — 記錄下來的值本身可以加減、可以算平均的那種欄位。  
　　*例*：你的資料中噸位 42.6 千噸與靠泊時間 18.4 小時是量化變數；船型是貨櫃、散裝、油輪，只能分類計次，屬質性變數。  
　　*易混*：量化變數 ≠ 只要是數字就算。船席編號 3 號、5 號雖然寫成數字，但平均船席「4 號」沒有意義，它其實是質性變數。

**Levels of Measurement（測量尺度）** — 同樣是一欄資料，依「能不能排序、能不能相減、能不能講幾倍」分成四個等級。  
　　*例*：船型是名目；靠泊優先順序第 1、2、3 順位是順序；海水溫度 25 度是區間；噸位與靠泊時間是比率，因為 0 小時代表真的沒靠泊。  
　　*易混*：區間尺度 ≠ 比率尺度。20 度不是 10 度的兩倍熱，但 40 千噸確實是 20 千噸的兩倍重，只有比率尺度能講倍數。

**Random Sampling（隨機抽樣）** — 用一套讓每個對象都有機會被抽中的機械程序來挑資料，而不是憑感覺挑。  
　　*例*：把當月 800 筆進港紀錄編號 1 到 800，用 Excel 亂數抽出 50 個編號，這是簡單隨機抽樣；若先依船型分成三堆再各抽一部分，則是分層抽樣。  
　　*易混*：隨機 ≠ 隨便。挑「剛好停在眼前的 50 艘」是便利抽樣，會系統性偏向某些船型，之後所有推論都不成立。

**Frequency Distribution（次數分配）** — 把連續的數值切成幾段，數一數每一段裡面有幾筆。  
　　*例*：把 50 艘的噸位以組距 10 切成五組：20 到 29 有 7 艘、30 到 39 有 13 艘、40 到 49 有 15 艘、50 到 59 有 9 艘、60 到 69 有 6 艘，合計 50 艘。  
　　*易混*：次數分配 ≠ 原始資料。分組後你只剩「某組有幾艘」，用組中點回推的平均 43.3 千噸與原始的 42.6 千噸會有落差。

### 描述資料

**Mean（平均數）** — 全部加起來再除以筆數，代表資料的重心。  
　　*例*：50 艘船的靠泊時間加總 920 小時，除以 50 得到 18.4 小時。  
　　*易混*：平均數 ≠ 一般情況。只要有幾艘船卡港 40 小時以上，平均就會被拉高，此時中位數更能代表「典型的一艘船」。

**Median（中位數）** — 把資料從小排到大，站在正中間的那個值。  
　　*例*：50 筆是偶數，取排序後第 25 與第 26 筆平均，例如 17.2 與 17.6 得中位數 17.4 小時，比平均數 18.4 小時低。  
　　*易混*：中位數 ≠ 平均數。兩者差距本身就是資訊，中位數比平均數低代表資料右偏，有少數超長靠泊的船。

**Standard Deviation（標準差）** — 每筆資料離平均大約有多遠，用原始單位表示的一個代表性距離。  
　　*例*：靠泊時間標準差 s = 6.2 小時，若分布接近常態，約七成的船會落在 18.4 加減 6.2，也就是 12.2 到 24.6 小時之間。  
　　*易混*：標準差 ≠ 變異數。變異數是 6.2 的平方等於 38.4，單位是「小時平方」沒辦法解釋，所以報告一律寫標準差。

**Coefficient of Variation（變異係數）** — 把標準差除以平均數，換成百分比，讓單位不同的兩欄可以比誰比較不穩定。  
　　*例*：噸位的變異係數 12.2 除以 42.6 等於 28.6%，靠泊時間 6.2 除以 18.4 等於 33.7%，所以靠泊時間的相對變異比噸位大。  
　　*易混*：變異係數 ≠ 標準差。12.2 千噸的數字比 6.2 小時大，但那只是單位不同；換成百分比後，反而是靠泊時間比較不穩定。

**z-score（z 分數）** — 某一筆資料比平均高或低了幾個標準差。  
　　*例*：一艘靠泊 30 小時的船，z = 30 減 18.4 再除以 6.2 等於 1.87，代表它比平均高出 1.87 個標準差。  
　　*易混*：z 分數 ≠ 百分位。z = 1.87 在常態分配下約落在第 97 百分位，但資料若不常態，這個換算就不成立。

**Interquartile Range（四分位距）** — 把資料排序後切四等分，中間那一半的寬度。  
　　*例*：Q1 = 14.0 小時、Q3 = 22.5 小時，IQR = 8.5 小時；上界 22.5 加 1.5 乘 8.5 等於 35.25，所以靠泊 38 小時那艘在盒鬚圖上會被畫成離群點。  
　　*易混*：四分位距 ≠ 全距。全距 38 減 6 等於 32 小時，整個被那一艘極端值決定；IQR 只看中間一半，不受極端值影響。

### 機率與機率分配

**Mutually Exclusive Events（互斥事件）** — 兩件事不可能同時發生，發生了一個就一定沒發生另一個。  
　　*例*：隨機抽一艘船，「是貨櫃船」與「是油輪」互斥，所以 P 等於 0.46 加 0.18 等於 0.64，可以直接相加。  
　　*易混*：互斥 ≠ 獨立。互斥事件其實高度相關，知道它是貨櫃船就完全確定它不是油輪；獨立才是「知道一個對另一個毫無幫助」。

**Random Variable（隨機變數）** — 一條把「隨機結果」轉成數字的規則，結果還沒出來之前你不知道會是多少。  
　　*例*：X 代表隨機抽一艘船的靠泊時間，是連續型；Y 代表一小時內進港的船數，是離散型。  
　　*易混*：隨機變數 ≠ 它的值。X 是那條規則，抽到之後得到的 18.4 小時是實現值，公式裡大寫小寫不同就是在分這兩者。

**Expected Value（期望值）** — 每個可能結果乘上它發生的機率再全部加起來，代表長期平均會拿到多少。  
　　*例*：若貨櫃、散裝、油輪的機率為 0.46、0.36、0.18，靠泊費分別為 8、5、12 萬元，期望值 = 0.46×8 + 0.36×5 + 0.18×12 = 7.64 萬元。  
　　*易混*：期望值 ≠ 最可能出現的值。7.64 萬元這個金額其實一次都不會真的收到，它是長期平均而不是眾數。

**Binomial Distribution（二項分配）** — 固定做 n 次、每次只有成功或失敗、成功機率都一樣時，成功次數的分配。  
　　*例*：隨機抽 10 艘船，每艘是貨櫃船的機率 0.46，貨櫃船艘數服從 B(10, 0.46)，期望 10 乘 0.46 等於 4.6 艘。  
　　*易混*：二項 ≠ 卜瓦松。二項有固定的試驗次數上限 10 艘，卜瓦松是在一段時間內計次，沒有上限。

**Poisson Distribution（卜瓦松分配）** — 在一段固定時間或空間裡，某件事平均發生幾次時，實際發生次數的分配。  
　　*例*：平均每小時 1.5 艘船進港，某一小時恰好進 3 艘的機率為 e 的負 1.5 次方乘 1.5 的三次方除以 3 階乘，等於 12.6%。  
　　*易混*：一小時的 λ ≠ 兩小時的 λ。要算兩小時內進 3 艘，必須先把 λ 從 1.5 換成 3.0，照抄 1.5 就會算錯。

**Normal Distribution（常態分配）** — 中間高兩邊低、左右對稱的鐘形分配，只要知道平均和標準差就完全決定它的形狀。  
　　*例*：若噸位近似常態，平均 42.6、標準差 12.2，超過 60 千噸的比例：z = 60 減 42.6 再除以 12.2 等於 1.43，查表得左側面積 0.9236，右尾為 7.6%。  
　　*易混*：查表查到的 0.9236 ≠ 超過 60 千噸的機率。課本的 z 表給的是 z 左邊的累積面積，要問「超過」就必須再用 1 去減。

**Central Limit Theorem（中央極限定理）** — 不管原始資料長什麼樣，只要每次抽夠多筆再算平均，這些平均數會排成常態分配。  
　　*例*：靠泊時間本身右偏，但每次抽 50 艘算一個平均，這些平均數會近似常態，中心落在母體平均 μ，手上這批估為 18.4 小時，標準差為 6.2 除以根號 50 等於 0.88 小時。  
　　*易混*：中央極限定理講的是「樣本平均數」的分配 ≠ 原始資料的分配。原始資料再怎麼抽都還是右偏，變常態的是平均數。

### 估計與信賴區間

**t Distribution（t 分配）** — 母體標準差未知、只能用樣本標準差代替時，改用的那個比常態略胖尾的分配。  
　　*例*：n = 50 所以自由度 49，95% 雙尾臨界值 2.010，比常態的 1.96 大一點點，這就是為了補償用 s 取代 σ 的不確定。  
　　*易混*：t ≠ z。n 越大 t 越接近 z，n = 50 時只差 0.05；但 n 小到 10 幾筆時差距就很明顯，不能混用。

**Confidence Interval（信賴區間）** — 用樣本算出一段範圍，用來包住那個你不知道的母體數值。  
　　*例*：50 艘的靠泊平均 18.4 小時，95% 信賴區間為 18.4 加減 1.8，也就是 16.6 到 20.2 小時。  
　　*易混*：「母體平均有 95% 機率落在 16.6 到 20.2」是錯的。μ 是固定的，正確說法是同樣程序重做 100 次，約有 95 個區間會蓋住 μ。

**Margin of Error（誤差界限）** — 信賴區間的半寬，也就是推估值上下可以差多少。  
　　*例*：臨界值 2.010 乘標準誤 0.88，誤差界限為 1.8 小時。想縮到 0.9 小時，樣本數要放大約四倍到 200 艘。  
　　*易混*：誤差界限 ≠ 測量誤差。它只反映「抽樣抽到不同船」造成的不確定，碼頭人員把時間記錯不包含在內。

### 假設檢定

**Null Hypothesis（虛無假設）** — 先假定「沒差異、沒效果」是真的，再看資料跟這個假定有多不合。  
　　*例*：H0 寫成「全港平均靠泊時間等於 20 小時」，接著用 50 艘的資料檢查 18.4 小時離 20 小時夠不夠遠。  
　　*易混*：H0 ≠ 你想證明的事。等號一定寫在 H0，你真正想主張的放在 H1，整套程序是在「反證」H0。

**Alternative Hypothesis（對立假設）** — 你真正想主張的那句話，寫成 H0 不成立時剩下的可能。  
　　*例*：若只想知道有沒有不同，H1 寫「不等於 20 小時」屬雙尾；若港務處只在意有沒有變短，H1 寫「小於 20 小時」屬左尾。  
　　*易混*：單尾 ≠ 雙尾。方向必須在看資料之前就決定，先看到 18.4 比 20 小才改成左尾，等於把自己的誤判機率偷偷放大一倍。

**Significance Level（顯著水準 α）** — 你事先願意承擔的誤判上限，通常訂 0.05。  
　　*例*：取 α = 0.05、自由度 49 的雙尾檢定，臨界值為正負 2.010，t 值超出這個範圍才拒絕 H0。  
　　*易混*：α ≠ p 值。α 是你動手之前自己訂的門檻，p 值是資料算完才跑出來的數，兩者相比才做決策。

**p-value（p 值）** — 先當虛無假設是真的，那麼看到目前這種結果或更極端結果的機率有多小。  
　　*例*：t = 18.4 減 20 再除以 0.88 等於負 1.82，自由度 49 的雙尾 p 值約 0.075，大於 0.05，所以不拒絕「平均等於 20 小時」。  
　　*易混*：p 值 ≠ H0 為真的機率，也 ≠ 差異有多大。p = 0.075 不代表 H0 有 92.5% 機率成立，只代表這份資料對 H0 的反證力道不夠。

**Type I Error（型一錯誤）** — 實際上沒有差異，你卻宣稱有差異。  
　　*例*：全港平均真的就是 20 小時，但你抽到的這 50 艘剛好偏短，於是下結論「不是 20 小時」；α = 0.05 表示長期每 20 次約犯 1 次。  
　　*易混*：型一 ≠ 型二。型一是無中生有，型二是視而不見；在同一份樣本數下壓低一個就會抬高另一個。

**Type II Error（型二錯誤）** — 實際上有差異，你卻沒能把它抓出來。  
　　*例*：全港平均其實是 18 小時，但 50 艘的證據不夠強，p = 0.075 沒有跨過 0.05 的門檻，於是你沒拒絕 H0，真差異就被漏掉了。  
　　*易混*：不拒絕 H0 ≠ H0 成立。正確寫法是「沒有足夠證據說不等於 20 小時」，不能寫成「已證實等於 20 小時」。

**Paired Samples（成對樣本）** — 同一批對象在兩種情況下各量一次，兩組數字是一對一配好的。  
　　*例*：挑 15 艘常來的船，記錄颱風前與颱風後各一次靠泊時間，先算出 15 個差值，再對這些差值做單一樣本 t 檢定。  
　　*易混*：成對 ≠ 獨立。兩群完全不同的船才是獨立樣本；把成對資料當獨立處理，配對本來消掉的船與船差異會跑回誤差裡，真正的前後差異就被蓋住了。

### 關聯與多組比較

**Correlation Coefficient（相關係數 r）** — 一個介於負 1 到 1 的數，講兩欄資料一起變動的方向與緊密程度。  
　　*例*：50 艘船的噸位與靠泊時間 r = 0.68，屬中度正相關，噸位越大靠泊通常越久。  
　　*易混*：相關 ≠ 因果，也 ≠ 斜率。r = 0.68 沒有單位，迴歸斜率 0.35 的單位是「小時每千噸」，兩者不是同一件事。

**Regression Line（迴歸線）** — 畫一條最貼近所有資料點的直線，讓你能用其中一欄的數字去預測另一欄。  
　　*例*：用 Excel 迴歸工具配得 ŷ = 3.5 + 0.35x，一艘 40 千噸的船預測靠泊 3.5 加 14.0 等於 17.5 小時；r² = 0.68 平方等於 0.46，表示噸位能解釋 46% 的變異。  
　　*易混*：迴歸線 ≠ 可以外推到任何 x。你的 50 艘只涵蓋 20 到 70 千噸，拿這條線去預測 200 千噸的巨輪並無依據。

**Chi-square Test（卡方檢定）** — 比較「實際數到的次數」跟「若兩件事無關應該出現的次數」差多少。  
　　*例*：把靠泊超過 20 小時記為延誤，50 艘中有 20 艘延誤，檢定船型與延誤有無關聯；3 乘 2 表自由度為 2，貨櫃船 23 艘的期望延誤數為 23 乘 20 除以 50 等於 9.2 艘，實際只有 6 艘。  
　　*易混*：卡方用的是次數 ≠ 百分比或平均數。把貨櫃船的延誤率 26% 填進表格算卡方是錯的，一定要填原始的 6 艘延誤與 17 艘未延誤。

**ANOVA（變異數分析）** — 一次檢定三組以上的平均數是不是全都一樣。  
　　*例*：貨櫃 16.2 小時、散裝 21.5 小時、油輪 17.9 小時，用 F(2, 47) 檢定三者是否至少有一組與眾不同。  
　　*易混*：ANOVA ≠ 做三次 t 檢定。兩兩各比一次會讓整體型一錯誤率從 5% 升到約 14%，這正是 ANOVA 存在的理由。

### 進階：跨章節觀念

**Sampling Distribution（抽樣分配）** — 同一種算法重複做在無數份樣本上，得到的那一堆數字自己排出來的分配。  
　　*例*：換一批 50 艘重算，平均可能變成 17.9、19.1、18.2 小時；把「抽 50 艘算一次平均」重複無限次，這些平均數會以母體平均 μ 為中心散開，標準差只有 0.88 小時。  
　　*易混*：抽樣分配 ≠ 樣本的次數分配。次數分配是那 50 艘畫得出來的圖，標準差 6.2 小時；抽樣分配是想像中無數個平均數的圖，標準差 0.88 小時，而 Ch7 的信賴區間與 Ch8 的 p 值全都蓋在後者上。

**Standard Error（標準誤）** — 換一批樣本重算一次，算出來的統計量大約會晃動多少。  
　　*例*：靠泊時間 SE = 6.2 除以根號 50 等於 0.88 小時；Ch7 信賴區間的半寬 1.8 小時與 Ch8 t 值的分母都是它，Ch9 比兩組時也是先各算一次標準誤再合併。  
　　*易混*：標準誤 ≠ 標準差。6.2 描述「船與船之間」差多少，0.88 描述「平均數本身」有多不準；多收資料只會讓 0.88 變小，6.2 不會。

**Degrees of Freedom（自由度）** — 扣掉你已經從資料裡估計掉的東西之後，還剩幾個數字可以自由變動。  
　　*例*：Ch3 用 50 筆算標準差時自由度是 49；Ch7 與 Ch8 的 t 查表也用 49；Ch12 三組 ANOVA 用 F(2, 47)；Ch11 的 3 乘 2 卡方表用 (3−1)(2−1) = 2。  
　　*易混*：自由度 ≠ 樣本數。它由檢定結構決定：單一樣本 t 是 50 減 1 等於 49，三組 ANOVA 是 50 減 3 等於 47，卡方只看表格大小 (3−1)(2−1) = 2，與 50 筆無關。

## GitHub 基本操作（新手看這裡）

> 本課程作業以 Canva 答題卡繳交，**不需要用 GitHub 交作業**。以下 Git 基本操作供你檢視本課程 repo、做期末報告的版本管理，以及其他課程（如資料庫系統及設計）使用。

### 一、第一次設定（只做一次）

1. 到 <https://github.com> 註冊 GitHub 帳號。
2. 安裝 Git：<https://git-scm.com/download/win>（Windows）。
3. 打開命令提示字元或 VS Code 終端機，設定你的名字與 Email（要跟 GitHub 帳號一致）：

```bash
git config --global user.name "你的名字"
git config --global user.email "你的GitHub註冊Email"
```

### 二、取得課程 / 專案 repo（複製到自己電腦）

```bash
git clone https://github.com/帳號/repo名稱.git
cd repo名稱
```

### 三、交作業或存檔的三步驟：add → commit → push

```bash
git add .                      # 把這次的變更加入暫存區（. 代表全部檔案）
git commit -m "完成第3週作業"   # 把暫存區的變更存成一個版本，-m 後面寫這次做了什麼
git push                       # 把本機的版本上傳到 GitHub
```

> 口訣：**add 收東西 → commit 存檔（要寫說明）→ push 上傳**。三步驟每次都一樣。

### 四、常用查看指令

| 指令 | 作用 |
|------|------|
| `git status` | 看目前有哪些檔案改了、加了、還沒 commit（最常用，動手前先打這個） |
| `git log --oneline -5` | 看最近 5 個版本；`HEAD -> main` 那一行就是你**現在所在的位置** |
| `git rev-parse --short HEAD` | 只印出目前 HEAD 的版本代號（7 碼） |
| `git branch` | 看目前在哪個分支（前面有 `*` 的就是目前所在） |
| `git diff` | 看改了哪些內容（還沒 add 的部分） |
| `git pull` | 把 GitHub 上別人（或老師）的最新版本拉下來 |

> **HEAD 是什麼**：HEAD 就是「你現在站在哪一個版本上」的指標。打 `git status` 會看到 `On branch main`（在哪個分支），打 `git log --oneline -5` 會看到 `(HEAD -> main)` 標在最新版本上——那就是 HEAD 現在的位置。
