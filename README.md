## 作業繳交方式

本課程採用 **Fork + Pull Request** 流程繳交作業：

1. Fork 本 Repo 到你的 GitHub 帳號
2. 在你的 Fork 中完成每週作業，放在對應資料夾（`week01/`、`week02/` …）
3. 發 Pull Request 回本 Repo 繳交，PR 標題格式：`學號_姓名_weekNN`

每週作業檔案格式：Excel（`.xlsx`）或手寫拍照（`.jpg`／`.pdf`），檔名 `weekNN_學號.副檔名`。

### 第 1 週｜課程簡介與統計工具環境（2026/09/09）

- 對應教科書：課程大綱
- 教學內容：
  - 課程大綱、評分方式、隨堂作業與小考規則
  - GitHub 帳號建立、Fork＋PR 繳交流程
  - Excel 資料分析工具箱啟用、計算機統計功能
- 隨堂作業：作業1：填寫個人資料表單、完成分組，安裝並截圖統計工具（Excel 資料分析工具箱或計算機統計模式）

### 第 2 週｜統計學的本質（2026/09/16）

- 對應教科書：Ch1 The Nature of Probability and Statistics
- 教學內容：
  - 1-1 敘述統計與推論統計
  - 1-2 變數與資料類型：質性／量化、離散／連續、四種測量尺度
  - 1-3 資料蒐集與抽樣方法：簡單隨機、系統、分層、群集
  - 1-4 實驗設計：觀察研究與實驗研究
- 隨堂作業：作業2：從一則海事新聞找出 5 個變數，逐一判定質性／量化與測量尺度，並說明該新聞用的是哪種抽樣方法

### 第 3 週｜次數分配與統計圖（2026/09/23）

- 對應教科書：Ch2 Frequency Distributions and Graphs
- 教學內容：
  - 2-1 類別與分組次數分配表
  - 2-2 直方圖、次數多邊圖、肩形圖
  - 2-3 其他統計圖：長條圖、圓餅圖、時間序列圖、莖葉圖
- 隨堂作業：作業3：依 exercise.md 練習 2-4／2-6 的資料，用 Excel 建立分組次數分配表與直方圖，另畫一張肩形圖

### 第 4 週｜資料描述（2026/09/30）

- 對應教科書：Ch3 Data Description
- 教學內容：

  - 3-3 位置量數：z 分數、百分位數、四分位數、離群值
  - 3-4 探索式資料分析：五數摘要與盒鬚圖
- 隨堂作業：作業4：對一組 20 筆資料計算平均數、中位數、標準差、四分位數，判定離群值並畫盒鬚圖（Excel）

## Git 基本流程

### 首次設定（只需做一次）

```bash
git config --global user.name "你的姓名"
git config --global user.email "你的Email"
```

### Fork + Clone（每學期做一次）

1. 在老師的 Repo 頁面右上角點選 **Fork**
2. Clone 你的 Fork 到本機：

```bash
git clone https://github.com/你的帳號/115-1_STAT.git
cd 115-1_STAT
```

### 每週作業流程

```
把作業檔放進 weekNN/ → add → commit → push → 發 PR
```

```bash
git add .
git commit -m "完成第 2 週作業"
git push origin main
```

到 GitHub 你的 Fork 頁面點選 **Contribute** > **Open pull request**，標題 `學號_姓名_week02`。

### 同步老師的最新版本

Fork 頁面上方出現 `This branch is X commits behind pychang-ai:main` 時，點 **Sync fork** > **Update branch**，再回本機 `git pull origin main`。
