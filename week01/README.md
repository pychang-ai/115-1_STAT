## 作業1 學習單：統計工具就緒與我的第一組資料

### 一、繳交物
1. 個人資料表單（課堂連結）填寫完成的畫面截圖 1 張。
2. Excel 截圖 1 張：含下方「二」的 8 個數字、AVERAGE／MAX／MIN 三個公式，**截圖時點在公式儲存格上，讓公式列顯示公式**。
3. 手寫或打字回答「三」的兩個問題，各一句話。

### 二、我的第一組資料（每人不同）
把你的學號末 4 碼與生日月、日拆成 8 個一位數（例如學號末 4 碼 3172、生日 08/25 → 3, 1, 7, 2, 0, 8, 2, 5），輸入 Excel 的 A1:A8，計算：
- 平均數 `=AVERAGE(A1:A8)`
- 最大值 `=MAX(A1:A8)`
- 最小值 `=MIN(A1:A8)`

### 三、想一想
1. 這 8 個數字是「母體」還是「樣本」？從誰的角度看？
2. 本學期你會用 Excel 還是計算機做統計運算？為什麼？

### 四、評分要點（Pass／Fail）
- 三項繳交物齊全；公式列可見；「三」的回答不是空白。
