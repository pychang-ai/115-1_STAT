## 作業W01 學習單（1 題）

**題目**：把你的學號末 4 碼與生日月、日拆成 8 個一位數（例如學號末 4 碼 3172、生日 08/25 → 3, 1, 7, 2, 0, 8, 2, 5），輸入 Excel 的 A1:A8，用 `=AVERAGE(A1:A8)` 算平均數。

**資料**：自己的學號與生日（每人不同）。

**繳交物**：Excel 截圖 1 張：點在平均數儲存格上，讓公式列顯示 `=AVERAGE(A1:A8)`。

**評分要點（Pass／Fail）**：8 個數字與學號、生日一致；公式列可見。
